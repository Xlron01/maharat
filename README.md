# Maharat — فورم مهارات الفريق

فورم تفاعلي بالعربي (RTL) بيجمع مهارات فريق تقني: كل عضو يختار مهاراته من فئات جاهزة (أو يكتب مهارات حرة)، يحدد مستواه في كل مهارة، ونتائجه تظهر فورًا لكل الزوار مع تحديث لحظي كل ثواني.

**شغّال على:** https://maharat-opal.vercel.app/

## المميزات

- **فورم بالعربي RTL كامل** — خط Cairo، تصميم نظيف أبيض/أسود/رمادي، متجاوب مع الموبايل
- **9 فئات مهارات جاهزة** (ميكانيكا، إلكترونيات، برمجة، ذكاء اصطناعي...) بمستويات إجبارية لكل مهارة: مبتدئ / متوسط / متقدم / خبير
- **مهارات حرة** — خانة إضافية تكتب فيها أي مهارة مش موجودة في الفورم، بنفس نظام المستويات
- **نتائج مباشرة للكل** — أي زائر يشوف كل المشاركات بدون تسجيل دخول، مع بحث فوري بالاسم/المهارة وفلتر بالفئة (dropdown)
- **تعديل اختياراتك** — بياناتك محفوظة محليًا وبتقدر تعدل مشاركتك في أي وقت
- **روابط واتساب** — رقم التواصل بيتربط تلقائيًا بـ wa.me (مع تطبيع أرقام مصر المحلية +20)

## البنية التقنية

```
index.html          الصفحة كاملة (HTML + CSS + Vanilla JS، بدون أي framework)
api/
  submit.js         POST — استقبال مشاركة جديدة (validation + honeypot + rate limit)
  responses.js      GET — قراءة كل المشاركات
  _lib.js           طبقة التخزين المشتركة + validation
skills.json         الفئات والمهارات المسموحة (مصدر الحقيقة للـ validation)
```

**التخزين:** GitHub repo خاص عبر Contents API — ملف `data/responses.json` واحد بيتم قراءته/كتابته مع retry عند تعارض الـ SHA (لو اتنين بعتوا في نفس اللحظة). سبق الاستخدام Vercel Blob لكنه اتوقف بسبب حدود الاستهلاك.

**الحماية:**
- Validation كامل على الـ server: الاسم ≤60 حرف، رقم موبايل حقيقي، المهارات مقصوصة على القوائم المسموحة فقط (والمهارات الحرة مسموحة فقط تحت فئة "Other" وبحدود 2-60 حرف، والحد الأقصى 20 مهارة)
- Honeypot field للبوتات
- Rate limit: 50 مشاركة / 10 دقايق لكل IP
- التوكنات في environment variables فقط — مفيش أي credentials في الكود

## التشغيل محليًا

```bash
npm install
```

اعمل `.env.local` فيه:

```
GH_DATA_TOKEN=<GitHub token بصلاحية repo>
```

بعدين:

```bash
npx vercel dev
```

## النشر

المشروع متشر على Vercel. النشر:

```bash
vercel deploy --prod
```

متغيرات البيئة المطلوبة في Vercel (production + preview + development):
- `GH_DATA_TOKEN` — توكن GitHub بصلاحية `repo` للقراءة/الكتابة في repo البيانات

## الإعداد الأول (لو هتعمل نسخة جديدة)

1. اعمل repo خاص لتخزين البيانات (مثال: `<user>/maharat-data`)
2. حدّث `REPO` في `api/_lib.js` لاسم الـ repo الجديد
3. اعمل GitHub token بصلاحية `repo` وحطه في env vars باسم `GH_DATA_TOKEN`
4. عدّل `skills.json` لو عايز فئات/مهارات مختلفة
